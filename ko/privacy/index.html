Mortgage Tracker — 개인정보 처리방침

2026년 10월 4일 시행.

모든 언어 · 이용 약관 · 지원

이 방침은 iOS 앱 Mortgage Tracker(러시아어 이름: Ипотечник)가 어떤 데이터를 왜 수집하는지, 어디에 얼마 동안 보관하는지, 사용자가 무엇을 할 수 있는지 설명합니다. ‘당사’는 App Store의 앱 페이지에 표시된 앱 개발자를 말합니다.

요약

  • 앱은 계산에 입력한 숫자와 그 결과(주택 가격, 계약금, 금리, 기간, 상환액, 이자 등)를 분석용으로 전송합니다. 이는 금융 데이터입니다.
  • 앱은 소득을 묻거나 수집하지 않습니다.
  • 계산 이름과 직접 입력한 다른 텍스트는 어디에도 전송되지 않습니다.
  • 앱은 이름, 이메일 주소, 전화번호, 연락처, 정확한 위치를 수집하지 않습니다.
  • 데이터는 판매되지 않으며, 현재 버전에서는 파트너와 공유되지 않습니다.
  • 앱 안에서 분석을 끌 수 없습니다. 수집을 중단하는 방법은 제5조에 있습니다.

1. 수집하는 데이터

1.1. 계산 조건과 결과

계산을 실행하거나 시나리오를 다시 계산하면 앱은 다음을 전송합니다.

  • 계산 조건: 주택 가격, 계약금(금액 및 비율), 연 이자율, 대출 기간, 상환 방식(원리금균등 또는 원금균등), 통화 코드
  • 시나리오에 입력한 값: 중도상환 금액과 방식, 월세와 연간 인상률, 연간 부동산 가치 상승률
  • 결과: 대출 금액, 월 상환액, 총 상환액, 이자, 대출 금액 대비 이자, 최종 기간

앱은 소득이 얼마인지 묻지 않으며 소득, 급여, 저축, 다른 대출에 관한 정보를 전송하지 않습니다. 이것이 바뀌면 먼저 이 방침을 업데이트하겠습니다.

이 숫자들은 이름이나 Apple 계정과 연결되지 않고, 무작위 설치 식별자(1.3)에만 연결됩니다.

1.2. 이용 데이터

  • 연 화면과 수행한 작업: 계산, 저장, 삭제, 상환 일정표 내보내기, 시나리오 펼치기, 통화나 테마 변경
  • 계산 이름의 경우 이름을 바꿨다는 사실과 이름의 길이만 전송하며, 텍스트 자체는 전송하지 않습니다
  • 구독 이벤트: 구독 화면 표시, 선택한 기간, 구매 완료·취소·실패와 오류 코드, 구입 내역 복원
  • 광고가 켜져 있는 경우 광고 노출

1.3. 식별자

  • Firebase 설치 ID — 앱 설치 시 생성되고 재설치 시 바뀌는 무작위 식별자입니다. 이름, 이메일 주소, 전화번호를 포함하지 않습니다.
  • 광고 식별자(IDFA) — 광고에만 사용되며, iOS 요청 창에서 추적을 허용한 경우에만 사용됩니다. 앱 분석에는 IDFA를 사용하지 않습니다.

1.4. 기술 데이터

기기 모델, iOS 및 앱 버전, 인터페이스 언어, IP 주소로 추정한 대략적인 국가, 세션 길이, 기술 오류 코드.

1.5. 수집하지 않는 데이터

  • 저장한 계산의 이름, 직접 지정한 통화 기호, 그 밖에 직접 입력한 텍스트
  • 상환 일정표 PDF 및 CSV 파일: 기기에서 생성되며 어디로 보낼지는 사용자가 정합니다
  • 이름, 이메일 주소, 전화번호, 연락처, 사진
  • 정확한 위치
  • 결제 정보: 구독은 Apple이 처리하며 당사는 카드 번호나 Apple 계정 정보를 볼 수 없습니다

1.6. 기기에만 남는 데이터

저장한 계산과 그 이름, 앱 설정은 기기에 저장되며 당사로 전송되지 않습니다. 무료 작업 횟수(직접 입력한 값으로 시나리오 다시 계산, 상환 일정표 내보내기)는 기기의 iOS 보안 저장소(키체인)에 저장되며 앱을 다시 설치해도 유지됩니다.

2. 데이터 수집 목적

  • 앱 운영 및 개선: 사용자가 결과까지 도달하는지, 어떤 계산과 시나리오를 쓰는지, 어디서 오류가 생기는지 파악합니다.
  • 수익화: 구독 수요와 광고의 영향을 평가합니다.
  • 어떤 주택담보대출 계산이 이루어지는지 파악: 어떤 금액, 금리, 기간이 많이 쓰이는지 확인합니다. 이 통계는 향후 제휴 은행과의 서비스 가능성을 포함한 제품 개발에 활용됩니다.
  • 광고 표시(광고가 켜져 있는 경우).

당사는 사용자에게 법적 효과를 미치는 자동화된 결정에 데이터를 사용하지 않으며, 은행에 제공하지 않습니다.

3. 데이터를 받는 곳

  • Google LLC — 앱 분석 및 원격 구성(Firebase Analytics, Firebase Remote Config, Firebase Installations)과, 켜져 있는 경우 Google BigQuery로의 분석 데이터 내보내기를 처리하는 수탁자입니다. Google은 당사의 위탁에 따라 데이터를 처리합니다.
  • Google AdMob — 광고가 켜져 있는 경우. AdMob은 IP 주소 기반의 대략적인 위치, 광고 노출 및 탭 정보, 그리고 추적을 허용한 경우에만 광고 식별자를 받을 수 있습니다. 허용하지 않으면 개인 맞춤이 아닌 광고가 표시됩니다. Mortgage Tracker Pro를 구독하면 광고가 표시되지 않으며 AdMob으로 요청이 전송되지 않습니다.
  • Apple — App Store에서 구독 구매와 갱신을 자체 개인정보 처리방침에 따라 처리합니다.

Google 서버는 사용자가 거주하는 국가 밖에 있을 수 있습니다.

파트너. 현재 버전에서는 은행, 중개업체 및 기타 제3자에게 데이터를 제공하지 않습니다. 제공하게 되면 앱에서 별도의 동의를 받고 이 방침을 업데이트하겠습니다. 동의 전에 수집한 데이터는 파트너에게 제공하지 않습니다.

당사는 데이터를 판매하지 않습니다. 법률이나 당사를 구속하는 공공기관의 요청이 있는 경우 데이터를 공개할 수 있습니다.

4. 보관 기간

  • 설치 ID와 연결된 Firebase 분석 이벤트 — 수집일로부터 14개월
  • Google BigQuery로의 이벤트 내보내기(켜져 있는 경우) — 수집일로부터 3년 후 삭제
  • 식별자와 연결되지 않은 집계 통계 — 기간 제한 없음
  • Google AdMob의 광고 데이터 — Google의 규정에 따름
  • 기기의 저장된 계산과 설정 — 사용자가 삭제하거나 앱을 삭제할 때까지
  • 키체인의 무료 작업 횟수 — 기기를 초기화할 때까지
  • 지원 이메일 — 답변과 법적 의무 이행에 필요한 기간

5. 수집을 중단하는 방법

앱에는 분석을 끄는 스위치가 없으며, 별도의 동의 화면도 없습니다. 앱을 사용하면 이 방침에 설명된 데이터 수집에 동의하는 것입니다. 동의하지 않으면 앱을 사용하지 마십시오.

  • 수집을 완전히 중단 — 앱을 삭제하십시오. 삭제 후에는 더 이상 데이터가 전송되지 않습니다. 다시 설치하면 새 식별자가 생성되며 새 데이터는 이전 데이터와 연결되지 않습니다.
  • 광고 추적 거부 — iOS에서 설정 → 개인정보 보호 및 보안 → 추적, 또는 설정 → Mortgage Tracker → 추적 허용. 광고는 계속 표시되지만 개인 맞춤이 아니게 됩니다.
  • 저장한 계산 삭제 — 계산 내역 목록에서 계산을 쓸어 넘기십시오. 앱을 삭제해도 함께 삭제됩니다.
  • 구독 취소 — iOS 설정 → 사용자 이름 → 구독. 구독을 취소해도 분석에는 영향이 없습니다.

이 방침의 링크는 앱의 설정 → 앱 정보 → 개인정보 처리방침과 구독 화면에 있습니다.

삭제 요청. 수집된 데이터는 무작위 설치 식별자에만 연결되어 있으므로, 이름이나 이메일 주소로 특정인의 데이터를 찾거나 삭제할 수 없습니다. 제10조의 연락처로 문의하시면 사용자의 경우에 가능한 조치를 알려 드리겠습니다.

6. 아동

앱은 성인을 대상으로 하며 아동을 대상으로 하지 않습니다. 당사는 고의로 아동의 데이터를 수집하지 않습니다.

7. 보안

데이터는 암호화된 연결(HTTPS)로 전송됩니다. 분석 데이터와 내보낸 데이터에는 개발자만 접근할 수 있습니다. 어떤 네트워크나 저장소도 완전한 보안을 보장할 수는 없습니다.

8. 이 웹사이트

이 사이트는 GitHub Pages에서 호스팅됩니다. 당사는 분석 스크립트, 광고, 추적 쿠키를 추가하지 않습니다. GitHub는 자체 개인정보 보호 정책에 따라 사이트 요청을 처리합니다.

9. 변경

새 버전은 새 날짜와 함께 같은 주소에 게시됩니다. 파트너에게 데이터를 제공하는 것과 같은 중요한 변경은 적용 전에 앱에서 알려 드립니다.
